📌 CareNest – Healthcare Assistance App

🏥 CareNest

A healthcare Android application providing AI-based symptom checking, real-time chat, and video consultations.

🚀 Features
	•	AI-based symptom checker
	•	Doctor–patient real-time chat
	•	Video consultation using ZegoCloud
	•	Secure login with Firebase Authentication

🛠 Tech Stack
	•	Kotlin
	•	Firebase Authentication
	•	Firebase Realtime Database
	•	ZegoCloud SDK
	•	MVVM Architecture
	•	Kotlin Coroutines
